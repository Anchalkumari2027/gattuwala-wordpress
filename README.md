# Gattuwala Industrial — WordPress Theme & Preview

A modern, responsive custom WordPress theme and static showcase for **Gattuwala Energy Solutions** (Industrial B2B renewable & alternative energy solutions).

---

## 📁 Repository Structure

- `gattuwala-wordpress-theme/` — Complete custom WordPress theme files:
  - Templates (`front-page.php`, `page-about.php`, `page-contact.php`, archive and single templates)
  - Custom Post Types: Products, Services, Installed Plants
  - Contact Form Shortcode: `[gattuwala_contact_form]`
  - CSS & JS assets
- `preview.html` — Interactive static web preview of the theme design.
- `index.html` — Quick redirect to `preview.html`.
- `gattuwala-industrial.zip` — Ready-to-install WordPress theme zip file.

---

## 🚀 WordPress Theme Installation

1. Download or clone this repository.
2. In WordPress Admin, navigate to **Appearance → Themes → Add New → Upload Theme**.
3. Select and upload `gattuwala-industrial.zip`.
4. Activate the theme.
5. In **Settings → Permalinks**, click **Save Changes** once to flush rewrite rules for custom post types.
6. Create the primary navigation under **Appearance → Menus**.
7. Set up pages using the included custom templates (**About Gattuwala**, **Contact Gattuwala**).
8. Add products, services, and installation projects under their respective custom post type menus.

---
